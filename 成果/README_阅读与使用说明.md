# 未来智慧教学平台：阅读与使用说明

研究设计稿 v0.1｜2026-10-23

本成果从现有两份原始材料提取三层架构与教学数据资产要求，结合标准制定组织及教育主管部门的官方资料，形成面向学校自行治理、跨应用复用的体系设计。原件保持不变。

公开版本不含原始材料本身及校内项目材料；第四份联读文件与 `附件/原始文件核验.json` 仅保留来源标题和校验值，不复现原文。

## 一、建议阅读顺序

1. **先看架构**：`三层架构具体描述_v0.1.pdf`（8 页）及同名 Word。明确基础设施层、数据资产层、应用层的职责，以及三类核心数据的关系。
2. **再看完整标准设计**：`未来智慧教学平台_架构与标准体系_v0.1.pdf`（35 页）及同名 Word。包括架构、S0—S7 标准体系、标准研究和原始材料提取追踪。
3. **研讨条款和字段**：使用四份编号 Markdown、`附件/` 下的 CSV 及 `样例/` 下的 JSON。Markdown 是正文编辑源；Word 可直接用于会议修订。
4. **核查依据和验证范围**：查看 `03_标准研究与采用说明.md`、`附件/官方来源索引.csv`、`验证/验证说明.md` 和 `验证/结构与样例核验.json`。

## 三、体系的关键约定

- **三层**：基础设施提供采集与运行条件；数据资产层管理可解释、可追踪、可交换的教学对象；应用层使用资产开展教学，并回传新增内容和证据。
- **三类资产**：课程资源数据、教学过程资源与数据、学生认知状态数据。正式成绩与评分确认属于过程评价记录；掌握估计属于认知判断，两者保持关联。
- **八组规范**：S0 总则与公共模型，S1 课程资源，S2 教学过程与证据，S3 数据交换与接口，S4 应用与 AI 接入，S5 认知状态，S6 安全与生命周期，S7 质量与一致性。
- **标准组合**：xAPI/Tin Can 是同一技术路线。以 xAPI 组织学习事件，Common Cartridge 组织课程，QTI 交换题目与测验，CASE 标识目标和能力，LTI 接入工具；SCORM 用于既有课件兼容。认知状态由学校 S5 规范补足。
- **证据约束**：点击、时长、完成、得分与知识掌握分别表达；没有足够证据时返回 unknown 或 insufficient_evidence，不生成确定掌握值。
- **版本约束**：正式版、候选版和兼容版本分别记录；cmi5 Quartz 引用 xAPI 1.0.3，不能直接以 xAPI 2.0 替换。具体选择见研究说明。

## 四、版本性质及后续冻结事项

这是可供讨论和继续细化的研究设计稿，尚不是已正式发布的校级标准或可直接据此宣布兼容的产品认证规则。JSON 样例用于表达数据关系；当前未交付完整 JSON Schema、正式 xAPI Profile、可运行接口、全部课件转换器或一致性测试平台。

进入实施前需冻结学校标识域、主数据映射、知识与能力框架、量尺定义、实际访问角色、生命周期规则、接口和 Schema 版本及标准实现子集。认知模型还需开展学科测量、校准与教学效果研究。T01—T16 是后续真实系统测试设计，本次未执行这些系统测试。

## 五、维护与复现

正文调整后，以 `01`—`04` Markdown 为源同步 Word 与 PDF；若直接修改 Word，应将定稿修订回写 Markdown，避免出现两个不一致的版本。

`编制工具/生成附件.py` 会重建字段/事件/来源 CSV、合成样例和架构图；`编制工具/生成文档.py` 调用 Pandoc 与 python-docx 生成 Word；PDF 由 LibreOffice 转换；`编制工具/验证附件.py` 使用 pypdf 检查文档和样例。需要原件完整性检查时，保持本目录与 `原始文档/` 为同级目录。验证脚本在原始开始快照存在时额外检查一次初始快照，临时文件清理后该项不再运行。

本次使用本机现成的 Python 运行时、Pillow、python-docx、pypdf、Pandoc 和 LibreOffice。脚本中的字体、Pandoc 路径适用于本机 macOS；在其他环境复现时应调整运行路径和可用中文字体（文档采用 Arial Unicode MS，架构图采用 macOS Heiti 字体）。PDF 转换建议使用新的独立 LibreOffice 用户配置目录，避免旧字体替换设置影响排版。重新生成会产生临时目录，交付前应检查渲染并清理。

来源状态以 2026-10-23 的查阅记录为准；标准更新后应重新核验官方状态、适用范围和实现兼容性。
