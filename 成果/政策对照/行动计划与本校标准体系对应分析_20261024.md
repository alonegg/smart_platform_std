# 《“人工智能+教育”行动计划》与本校三层架构、S0—S7 标准体系对应分析

编制日期：2026-10-24。对照基线：2026-10-23 研究设计稿 v0.1。本文为政策对照分析，未修改原架构与标准正文。

## 一、核心判断

本校体系最明确的政策定位是：**面向智能教学应用，建设可共享、可解释、可交换、可治理的教学数据资产底座，并形成应用接入、安全治理与质量验证的校内标准体系。**

政策依据集中在第四部分第（十）项“智能教育基座”、第（十一）项“智能应用体系”，第五部分第（十四）项“条件保障”中的标准规范、第（十六）项“安全屏障”。主要业务目标对应第三部分第（六）项学生学习、第（七）项教师教学，并部分支撑第（八）项教育评价和第四部分第（十二）项未来教育空间。

若按报道的四块归纳，我们横跨“智能基础设施—智能教学—创新生态”，对“素养与人才”提供承载条件。当前标准的主线是数据与应用的共同规则；AI 素养课程、培养方案、师资培训以及人才评价制度，需要另有业务设计。

“直接对应”只表示本校设计职责与政策任务有直接关联，不表示覆盖该任务全部要求，更不表示已审定、已实施或通过认证。全文矩阵中的关联强弱是本次分析判断，国家文件未对本校 S0—S7 作任何认定。

## 三、怎样理解行动计划的四个主体方向

正式结构包括“一、总体要求”“二、推动人工智能人才培养与素养提升”“三、促进人工智能与教育深度广泛融合”“四、建强‘人工智能+教育’基础环境”“五、优化‘人工智能+教育’发展生态”“六、组织实施”。

| 报道的归纳 | 正文对应 | 对分析的影响 |
|---|---|---|
| 素养与人才 | 第二部分，第（一）—（五）项 | 区分学生学 AI、专业人才培养、社会通识与教师素养；不能只按平台功能理解 |
| 智能教学 | 第三部分，第（六）—（九）项中的主要教学场景 | 原文还部署教育治理、科学研究；用“智能教学”概括整个第三部分会缩窄范围 |
| 智能基础设施 | 第四部分，第（十）—（十二）项 | 范围包含算力、数据、模型、工具、应用体系和教育空间，超出硬件设施 |
| 创新生态 | 第五部分，第（十三）—（十六）项 | 同时涉及交叉研究、制度与标准、队伍与投入、国际合作以及安全治理 |

本校“三层”是系统职责划分，政策“四块”是任务归纳，二者不是同一维度，不能强行一层对应一块。

## 四、三层架构在政策中的位置

| 本校层次 | 主要政策关联 | 本校应承担的职责 | 当前边界 |
|---|---|---|---|
| 基础设施层 | （十）（十二），安全贯穿（十六） | 教学现场采集、网络、算存、备份恢复、运行保障，按条件接入外部公共能力 | 现稿为架构职责描述；尚无完整算力调度、容量、终端建设及运维标准 |
| 数据资产层 | （十）（十一）（十四）（十六），服务（六）（七） | 将课程资源、过程证据、认知判断组织为统一标识、可授权交换和复用的资产 | 本轮标准的主要建设对象；尚需冻结可执行 Profile 并做真实验证 |
| 可插拔应用层 | （六）（七）（十一）（十二），部分（八） | 备课、学习、评价、辅导等应用按契约调用数据并回传结果 | S4 规定接入与责任，应用功能、教育效果和模型能力须分别验证 |

政策第（十）项强调公共基座与资源整合。本校可优先明确本地教学数据的语义、质量、权利与开放接口，结合实际接入成熟算力、模型和工具。采用三层架构本身不意味着学校需要独立训练通用教育大模型。

## 六、16项任务的范围分布

| 政策任务 | 本轮关系 | 主要判断 |
|---|---|---|
| （一）中小学生人工智能教育 | 跨学段扩展支撑 | 可复用课程、交换和证据机制；不属于当前高校教学方案的直接实施对象 |
| （二）高层次人才 | 支撑 | 可以承载高校 AI 公共基础课和交叉课程；尚无人才培养方案和课程实质内容 |
| （三）职业教育专业升级 | 范围外，可扩展 | 当前没有职业教育专业体系、岗位能力和实训建设设计 |
| （四）全社会通识教育 | 支撑 | 可复用课程与评价记录；社会开放、微证书和学分银行互认规则另需设计 |
| （五）教师智能素养技能 | 部分支撑 | 可用于培训资源、测评工具接入和过程留痕；尚无教师素养框架、分层培训和认证制度 |
| （六）学生学习 | 核心业务支撑 | S1/S2/S4/S5 支撑智能学伴与学习档案；当前不含德智体美劳全领域、特殊教育等全部要求 |
| （七）教师教学 | 核心业务支撑 | 课程资源、教学证据、AI 接入与诊断形成课前课中课后共同基础；应用和效果仍待验证 |
| （八）教育治理 | 部分支撑 | S2/S5 支撑课程范围的过程评价；未覆盖人才供需、就业、专业设置、校园安全等治理领域 |
| （九）科学研究 | 范围外，局部支撑 | research 交换 Profile 可提供获准研究数据；没有科学智能体、智能实验集群和科技成果交易设计 |
| （十）智能教育基座 | 直接对应其中数据与接口部分 | 三层架构与 S0/S1/S3/S6/S7 形成校级数据基础规则；未覆盖国家算力平台、全部语料与大模型研发任务 |
| （十一）智能应用体系 | 直接对应其中数据公共能力和应用接入部分 | S3/S4/S5/S7 支撑复用、协作和接入验证；国家平台上线遴选、学习社区和中试基地另属组织建设 |
| （十二）未来教育空间 | 数据与应用支撑 | 可支撑智慧慕课、数字教材和场景学习；尚无空间、终端和实践中心完整建设方案 |
| （十三）研究创新 | 有限支撑 | 证据化认知记录和合规研究数据为研究提供条件；未开展 AI 社会实验、因果评估与联合攻关机制建设 |
| （十四）条件保障 | 直接对应其中标准规范工作 | S0—S7 是校内规范研制的具体载体；队伍、投入和制度责任尚需组织文件 |
| （十五）国际合作 | 技术准备，非直接成果 | 国际协议兼容有助资源交换；不能据此声称参与国际标准制定或已开展合作 |
| （十六）安全屏障 | 直接对应其中数据与应用治理部分 | S4/S6/S7 建立权限、审核、生命周期、验证基础；模型安全、备案适用性、风险预警应急仍需专项细化 |

完整结构化条目及条款依据见 `政策任务_标准条款对应矩阵.csv`。不计算“覆盖率”：一项政策任务包含多种职责和不同实施主体，用条目命中数量计算比例会夸大本校方案的实际覆盖。

## 七、优先补充的五组内容

1. **把第（十四）项落成标准治理机制。** 在 S0 总则补政策依据、发布主体、业务与技术共同维护、版本复审和例外处理。成果是经学校程序审定的职责及维护规则。
2. **为第（十）项补语料用途与质量 Profile。** 在 S1/S3/S6 区分教学资源、检索知识库、评测集与训练语料，约定权利、来源、加工、去重、审查、更新及撤回。保存了课程文件不等于获得训练授权，也不等于高质量语料。
3. **为第（十一）（十四）（十六）项补 AI 应用评测与准入 Profile。** 在 S4/S7 定义课程内容准确性、证据引用、教学适配、工具权限、异常处理、群体适用性等能力和安全测试；在 S6 配套内容、模型、算法和伦理审核与运行应急。不得把数据结构、接口通过当成综合安全或教育效果通过。
4. **为第（二）（五）项单列素养培养与评价业务方案。** 明确学生和教师的能力框架、课程、情境任务、量规、培训及复核。S1/S2/S3 提供资源、证据和交换，S5 在适用范围支持学生能力记录；教师素养评价还需单独的对象和场景扩展，不能把现有学生认知规范原样套用。
5. **为第（六）（七）（十三）项建立试点及效果证据。** 选代表性课程和两个独立应用，先验证资源、过程、评价及撤权能正确流转，再分别开展认知方法验证与教育效果评价。另形成学校实施方案、责任分工和常态监督机制，对应第六部分组织实施。

以上是对现稿的增补建议，尚未成为 S0—S7 新条款。建议优先深化现有分工，避免在缺少新职责时不断新增编号。

## 八、可用于建设说明的表述

> 本体系依据《“人工智能+教育”行动计划》关于建强基础环境、培育智能应用体系、研制标准规范和筑牢安全屏障的部署，面向学生个性化学习和教师教学全过程，构建“基础设施—教学数据资产—可插拔应用”三层架构，研究制定课程资源、学习证据、数据交换、AI 应用接入、学习诊断及安全质量等校内规范，为学校智能教学应用的共建、共享、接入、评测和持续演进提供共同基础。相关规范将通过校内审定、真实课程试点和独立应用互操作验证逐步落实。
