# WP6 试点与度量方案

本包为“智慧教学-数据模型标准”提供学校组织真实教学试点前的候选方案，不是 D2 冻结、认证、符合性或教学有效性声明。范围为 P-COM/P-SUB/P-GRD/P-AI，认知诊断仅在另获用途批准时启用。依据 4.4.5.2、12.2.5，区分“合成样例通过 / 真实平台数据通过 / 未执行”：本包所有指标真实试点证据等级均为**未执行**；合成计算仅证明口径可算，不证明 T 用例通过。

## 文件与运行
在仓库根执行（Python 3.11+，仅标准库）：

```sh
python3 -m unittest discover -s 验证/试点方案/tools -v
python3 验证/试点方案/tools/check_pilot.py
python3 验证/试点方案/tools/compute_metrics.py
```

- 试点方案.md：课程、参与方、阶段、演练和部署回收清单。
- 任务脚本-T16.md、任务脚本-T26.md：人工组织的任务，不是浏览器自动化。
- 度量指标.csv：口径、阈值性质、隐私限制、证据等级；UTF-8 BOM。
- 放行条件对应表.csv：逐项条件、指标与证据，不以总体通过率抵消阻断。
- 临时假设.md：候选操作口径及可选方案，待 WP1 合并后并入统一登记。
- 发现的标准问题.md：按评议模板字段整理，尚未提交意见。
- 追溯表.csv：要素至所有产出及指标的导航。
- samples/合成试点记录.json：仅虚构数据，不存真实身份或密钥。
- tools/compute_metrics.py：只读输入、输出 stdout；定量口径由 CSV 的“计算规则”列驱动。
- tools/check_pilot.py、tools/test_pilot.py：一致性校验和反例测试。

## 局限
真实试点由学校组织，不在自动执行范围。核验类指标由人审查签署及系统证据，计算器不会从“清单存在”推断放行；不计算未经真实组织获得的成功率。标准未定值留待审定；未审定时输出“待审定”。空分母不作零成功率，输出空值与待审定；负值、未知规则及缺字段拒绝计算。样例隐私正则仅筛查常见形态，不是匿名化证明。未进行 Excel/辅助技术视觉检查。
追溯依据 12.10、12.11、D.3；OBJ-031、OBJ-034、EVT-003、EVT-013、EVT-018—EVT-020。
