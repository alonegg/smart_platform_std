# 参考校级公共服务候选假设（仅合成验证）

依据《智慧教学-数据模型标准》、WP0 第1轮修订建议及 WP1 H-01—H-28。
本实现不是正式 OAuth2、真实教务系统、两个独立应用、D2 冻结或真实试点通过证据。
未决定的真实业务仍关闭。参数不允许绕过 WP1 的 input/stored/receipt 校验。

| 编号 | 内容及依据条款 | 待决事项 | 可选方案 | 本实现采用方案/配置 |
|---|---|---|---|---|
| S-01 | 标识及精确线格式，5.1.7、7.2、8.6 | E12 | 类型化标识语法、学校登记语法、候选字符串 | 沿用 H-01/H-17；`identifier_policy` 可进一步收紧；ApplicationInstance 的 source_instance=object_id；目录状态独立存储，不注入业务对象。 |
| S-02 | 摘要不是来源证明，7.6.4 | E13 | RFC8785、Unicode 规范化、受控序列化字节 | 默认调用 WP1 payload_hash、逐事件 hash_envelope_members、H-11 序列化；`hash_serializer` 可用于比较候选，但结果仍必须满足当前 WP1 stored 校验，不兼容方案保持拒收而非绕过校验，摘要成员始终取对应事件定义。 |
| S-03 | 撤权期限与传播，8.6.6、8.7.4、11.5 | E14 | 学校审定异步上限、同步本地传播 | `max_revocation_delay` 默认 0 秒，仅表示本地同步合成实验；记录 delay_seconds/within_limit，不是学校 SLA。同步撤销绑定令牌，通知订阅方及授权课程；不声称已处置外部缓存/副本。 |
| S-04 | 接收端权威字段，5.3.3、7.2.3、7.2.4、T25 | E12 | 拒收、自行覆盖 | `receiver_field_policy='reject'`，沿用 H-09；当前 WP1 input 仅允许拒收，其他参数值构造时拒绝。不能用 CSS 或隐藏字段冒充删除。 |
| S-05 | 受理状态与持久化边界，7.6.2、8.7.3、8.8 | E12/E26 | 队列接受、证据库接受、真实参考对端 | sqlite 事务完成后返回 evidence_store；`received_stages` 默认 school_received/school_registered，source_persisted 留源应用确认；未接收业务不宣称任何阶段完成。内存库只保证进程内，可传文件路径；不代表断电耐久性/高可用验收。 |
| S-06 | 评分关系与教务对端，7.5、9.2.4、9.5 | E12/E23a/E26 | 学校 Profile 内嵌载荷、独立业务关系、真实教务接收 | GradeDecision 严格沿用 H-13；因其无 learner/submission/method/supersedes/basis 字段，库参数提供经 WP1 引用/Submission 校验的独立关系，保留原对象；状态 archived 与 registrar_status 仅为服务派生，绝不写进 GradeDecision。确认须追加新决定；事件必须引用先已登记且完成相应授权业务步骤的决定，不能仅靠事件改变决定状态。`registrar_statuses` 默认 accepted/rejected/quarantined，管理令牌模拟受控教务回执，不证明真实正式成绩数值一致。 |
| S-07 | 人员确认资格，5.2.7、7.5.2、9.2.4 | E12/E23a | 按 confirmation_scope_refs、学校角色映射、人工安排表 | `manual_scopes` 默认 grade.confirm/course.publish；`confirmation_roles` 默认 lead_instructor。须同时有当前人员 grant、grade.confirm、有效 TeachingAssignment 与对应 Offering；助教不自动取得确认权。用户会话用 delegated grant 的 subject_ref 模拟，令牌 access_mode 可选 user_session（WP1 grant 尚无该枚举）。 |
| S-08 | 方法准入在线边界，10.13.3、10.13.6、9.8.5 | E22/E12 | 当前在线查询、有效离线证明、缓存证明 | 只实现 sqlite 当前批准在线检查，无离线证明；用途与后果等级严格相等、人群用 `population_match` 默认成员匹配、时间左闭右开。暂停立即在本地阻断，不将 S-03 撤权时限套用为方法传播目标。保留批准与变更历史；不含真实模型阈值或教学效果。 |
| S-09 | 模拟凭证、假名及审计，11.5、11.10 | E12/E14 | 外部统一认证、学校 KMS/外部审计锚、本地 HMAC | 管理令牌仅供合成测试；本地每客户端 HMAC-SHA256，轮换旧 kid 立即失效，写操作 jti 一次性；假名 HMAC 包含实例与 learner_ref 的受控 JSON；`secret`、`admin_token`、`audience`、`clock` 可配置，文件库重新打开须重用 secret 才能维持假名稳定。审计链非签名、无外部锚，能检测链内修改，不能证明管理员未重算整链/截去链尾。 |
| S-10 | 修读轮次及范围，5.2、7.5、8.8 | E23a/E26 | 补考沿用 Enrollment、另建 Enrollment | 本阶段不决定轮次策略，不把 TaskAttempt 当轮次；仅保留 WP1 引用。对账限本服务事实数/传输数/duplicate/conflict/rejected，不声称 T07 跨应用完整对账或 T14 独立恢复通过。 |

运行：仓库根 `python3 -m unittest discover -s 验证/参考公共服务/tests -v`。
仅标准库及 WP1 校验器既有依赖；提供本地 stdlib HTTP 适配，真实令牌交换、外部通知送达与文档站点不在本阶段。

## 与 main 既有登记的对应关系

以 main 的[契约登记](../契约/临时假设.md)为准；同时核对[WP0 候选](../../维护/第1轮修订建议/临时假设.md)与[WP6 候选](../试点方案/临时假设.md)。下面是沿用关系，不创建或修改 H 编号，也不把本包候选上升为标准。

| 本包编号 | main 既有编号/条目 | 沿用与增量边界 |
|---|---|---|
| S-01 | H-01、H-02、H-17；WP0 E12 | 沿用字符串与实例标识约定；本地更严格策略不能放宽 WP1。 |
| S-02 | H-10、H-11、H-25；WP0 E13 | 沿用候选序列化与事件成员；不声称算法正式冻结或摘要证明来源。 |
| S-03 | H-17；WP0 E14；H-WP6-02 | 沿用外部审定期限；0 秒只描述同步进程内实验，不替代 WP6 合成建议的普通 60 秒/接替 3600 秒，不是 SLA；运行时记录机制建议补登。 |
| S-04 | H-09；WP0 E12 | 完全沿用 input 拒收接收端字段。 |

| S-07 | H-04、H-16、H-17；WP0 E12/E23a | 沿用委托主体、角色与服务身份边界；user_session 模拟绑定和默认角色映射建议补登，不冒充教务权威安排。 |
| S-08 | H-24；WP0 E22；H-WP6-03 | 沿用方法登记与用途批准分离、无真实阈值、不与教师耗时或撤权时限混用；精确匹配及在线实现增量建议补登。 |
| S-09 | H-04、H-17；WP0 E12/E14 | 沿用认证上下文和授权记录；HMAC 假名、模拟凭证与审计链实现细节建议补登，不替代学校密码及审计制度。 |

## 建议补登到 `验证/契约/临时假设.md` 的条目（尚未登记）

以下仅为本包 S 编号的新增部分建议，不占用正式 H 编号；正文表 E.1 的责任方裁定前不能用于真实业务许可。本包不修改契约文件。

- **S-03 增量**（E14；8.6.6/8.7.4）：本地同步记录延迟与课程通知的候选行为；可选异步上限或同步，仅采用进程内同步实验。
- **S-05 增量**（E12/E26；8.7.3）：阶段由接收端确认、source_persisted 待源方确认的参考实现；可选队列或本地证据库，本包采用 SQLite 事务。
- **S-06 增量**（E12/E23a/E26；7.5）：独立评分关系、先登记对象再登记事件和模拟教务接收；可选 Profile 字段/独立关系/原子命令，本包不注入 WP1 核心对象。
- **S-07 增量**（E12/E23a；9.2.4）：user_session 临时绑定人员 delegated grant、默认 lead_instructor 角色；可选独立会话授权/按 confirmation_scope_refs，本包参数化模拟。
- **S-08 增量**（E22/E12；10.13）：用途/后果等级精确匹配及人群成员匹配；可选学校范围判定器或有效离线证明，本包在线本地查询。
- **S-09 增量**（E12/E14；11.5/11.10）：本地 HMAC 凭证、假名与无外部锚审计链；可选外部统一认证/KMS/外部审计锚，本包仅合成机制证据。
