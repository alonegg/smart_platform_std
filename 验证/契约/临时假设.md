# 临时假设登记

供 WP0 提案及后续候选契约使用。下表只允许在标明的合成夹具内对选项参数化或并列验证，**未选定任何真实业务值或正式契约**。待决事项由正文表 E.1 的责任方裁定，D2 冻结前不作为正式符合性证据。

| 待决事项 | 临时假设／可选方案 | 使用边界 |
|---|---|---|
| E12 | 原型可对不同定位类型、嵌入对象的清单表示分别建候选夹具；需比较在共享路径逐项列嵌入对象与通过所属版本/局部标识表达的方案。标识符语法、缺失原因结构、词表、阶段 Schema、可选签名和精确线格式不在 WP0 选定。 | 只验证提案能覆盖所述场景，不提交冻结 Schema；不得让非时间定位伪造时值或给固定对象另造版本。 |
| E13 | 可比较经冻结待选算法规范化后计算摘要与对受控序列化字节计算摘要；是否另加签名或服务端鉴别待裁定。 | 不选算法或测试向量；事件摘要不代替来源证明，不混入已明确的交换包 SHA-256 要求。 |
| E14 | 夹具可模拟在学校审定期限内生效、超限两支，时限作为外部参数；恢复目标可比较分级候选值。 | 不设置同步／撤权延迟或 RPO/RTO 数值，不改变正文已给的 5% 过渡值与计分、关键提交零未解释缺口。 |
| E22 | 用虚构方法及批准验证在线查询、有效离线证明及超界阻断；可比较缓存证明有效边界，方法暂停传播目标独立审定。 | 不使用真实模型阈值、证明时限或批准，不将令牌撤权目标套用于方法暂停。 |
| E23a | 合成夹具并列允许补考沿用与另建 Enrollment，两支均保留独立 EnrollmentRound 及其前序引用；回执与对象关系待审定。 | 不将平台默认写成唯一教务规则，不以 TaskAttempt 指代轮次。 |
| E23b、E24 | 可分别输入有条件允许或不允许撤回、最高已确认分或教师指定、启用或关闭即时形成性帮助的合成业务配置。 | 不产生真实课程规则；人工确认、帮助条件及未决定业务关闭等已有约束不变。 |
| E26 | 是否使用参考对端或受控夹具为待选；夹具可先用于隔离联调。 | 夹具不计作两个独立应用，不证明完整 T14 或真实试点通过。 |
