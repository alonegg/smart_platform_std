# 智慧教学-数据模型标准

本标准面向不同的应用厂商、标准专家及学校相关部门，供其审阅、评议和提出意见。

公开阅读：[智慧教学-数据模型标准](https://stds.chunlin.ch/)。

- [当前标准 Markdown](标准/评审稿/智慧教学-数据模型标准.md)
- [可批注 Word](标准/评审稿/智慧教学-数据模型标准.docx)
- [评议意见表](标准/评审稿/评议意见表.docx)
- [编辑原则](AGENTS.md)
- [网站源码、构建与维护说明](designs/standards-portal/README.md)

标准包括第 1—12 章和附录 A—E，规定公共数据模型、课程资源、教学过程与学习证据、数据交换、
应用与 AI 接入、认知诊断、安全与权利、验证与运行。附录 A/B 为规范性附录；附录 C 提供评议指引，
附录 D 提供实施阶段与放行条件，附录 E 列出学校待决事项。

审阅宜定位到具体条款、字段、表格或能力 Profile，说明实际场景、具体问题、建议文字、依据与影响范围。
可从网站“提出意见”入口创建带格式的 GitHub Issue，也可填写评议意见表交给标准组织方。

**文件性质**：当前为征求意见稿。条文中的“应”表示拟议要求，不表示学校已经审定发布、系统已经实现或相关能力已通过验收。

## 使用与复现

网站从 `标准/评审稿/` 的受控文稿生成，构建与验证见网站目录 README。
正文、在线检索和下载文件保持一致，独立使用当前条款号。

`成果/编制工具/` 保存研究附件的生成和验证工具，样例为合成数据；工具与样例的验证范围以其说明为准。
