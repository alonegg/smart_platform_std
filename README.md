# 未来智慧教学平台：架构与数据资产标准体系

研究设计稿 v0.1｜2026-10-23

面向高校智慧教学平台的三层架构与教学数据资产标准研究，含 8 组规范、59 个条款、核心字段字典、
教学事件词表、国际与国内标准采用矩阵，以及可运行的附件生成与结构核验工具。所有样例数据均为合成数据。

**性质说明**：这是可供讨论和继续细化的研究设计稿，尚不是已正式发布的校级标准，也不构成产品的一致性
认证规则。文中"应"表示拟建系统的设计要求，不表示已实施或已通过验收。

## 复现

```bash
cd 成果
python3 编制工具/生成附件.py    # 重建 CSV、样例与架构图
python3 编制工具/验证附件.py    # 结构与样例核验
```

生成 Word 需 Pandoc 与 python-docx；PDF 由 LibreOffice 转换。脚本中的字体与路径为 macOS 环境，
其他环境需调整。
