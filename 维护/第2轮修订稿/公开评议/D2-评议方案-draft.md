# D2 技术契约与学校决定评议材料

状态为 draft。以下工程偏好、测试参数和表决选项供评议，保留附录 E 的并列方案、决定主体、前置依赖和决定前处理。冻结时应记录选择理由、受影响条款、契约版本、依赖版本、验收向量和决定签署。真实业务按正文与学校审定范围放行。

## E12 子包

| 子包 | 评审范围 | 冻结证据与依赖 |
|---|---|---|
| E12a 基础模型与线格式 | 字段适用性、命名空间、标识语法、版本分类与引用、关系基数、状态及其承载、缺失原因、权威写入、成员映射、Segment、文件判别、许可代码 | 对象及词表登记、权威来源、状态迁移和引用解析向量。确认后供 E12b–d 按版本引用 |
| E12b 教学与评分 | 逐事件契约及三阶段 Schema、轮次与尝试、授课安排与个人调整、课外事件范围、角色与进入方式、重试与对账回执、GradeDecision、教务归档 | 按事件与阶段校验正反例，关联 E23a 的教务决定；未审定用途继续关闭 |
| E12c 授权与内容读取 | 删除后引用、当前批准证明的控制契约、人员委托、scope 与令牌、auth_context、内容读取授权核验 | E22 提供方法治理输入，E26 记录承担方，适用 E14 的撤权边界。验收绑定目标和版本，核对正例与拒绝回执 |
| E12d 交换包与存量适配 | 交换包 Schema、objects、包外导出回执、可选签名、来源登记、隔离导入和恢复闭包 | 核对包内外字节、权利边界、来源与隔离记录。范围和对端按 E26 评审，依赖的 E12a–c 契约按版本引用 |

各子包可分批提交评审和冻结。仍有依赖未冻结的子包可先验证无关输入；相应正式验收或业务放行仍依赖完整、可复核的适用契约。共同变更统一评审并记录兼容性。

## 工程候选方向

| 待决项与条款 | 建议先验证的候选 | 核对点 |
|---|---|---|
| E13，7.6.4、7.6.5 | 在事件 Profile 的一个版本内唯一指定 RFC 8785 JCS，再对规范化 UTF-8 字节取 SHA-256 | 明确摘要覆盖成员、重复键的拒收、数字约束和超精度输入表示，按 RFC 保留 Unicode 原样。用跨语言向量验证，单独评审来源鉴别 |
| E12a，6.4.1 | 显式 locator_type 判别联合，用 JSON Schema oneOf 配合互斥校验；权威时长来自所属资源版本 | 混填或越界拒收；缺权威时长时记录未验证。现有候选 Schema 仍保留 source_duration_ms，在迁移对照中单测一致性 |
| E12a，5.1.3 a) | 默认限所属不可变记录内引用；具备批准场景时，用父记录引用加局部标识 | 用候选二元结构验证局部标识的作用域和父记录引用；不赋予独立版本 |
| E12b / E23a，7.5.11 | 参考实现先登记决定、再受理事件，原子提交由适用方案评估 | 重放、引用未解析、失败回滚和并发场景逐一验证。事件先到暂存方案保留在并列比较，额外估算超时、重放和对账成本 |
| E12b / E23a，8.7.6 | 教务归档采用独立回执类型 | 以具体决定版本关联，通用 accepted、旧回执及归档终态用对照向量测试 |
| E12d，8.2.5 | objects 只列所属对象版本，嵌入内容用所在路径与局部标识定位 | 验证清单定位可逆和字节一致性，比较清单体积 |
| E12c / E26，8.6.9 | 小范围试点评估登记的源应用提供读取，由校级公共服务统一核验令牌内省或短期绑定 | 校方先定承担方；核验令牌对目标对象版本、用途和授权的绑定。超出范围或不可核验即阻断；不因另有有效授权放开 |
| E12d / E26，8.4.6 | 正式供数严格检查，缺值历史数据进入隔离导入渠道 | 保存缺失原因、来源、目的与授权边界；隔离结果不得计入合法供数和正式对账 |
| E23a，5.2.2 | 请教务部门在首次相关契约冻结前审定本校补考、重修的统一口径 | 决定前同时验证沿用与另建 Enrollment 两支的 EnrollmentRound 和 prior_round_ref；普通任务重试另记 TaskAttempt |

RFC 8785 原文与序列化说明见 [RFC Editor](https://www.rfc-editor.org/rfc/rfc8785.html)。

## 学校决策参考档

以下数字仅作为演练输入。用实测容量、风险和现有学校制度核定正式阈值。E14 的临时 5% 阈值及未解释缺口为 0 的要求按正文执行。

| 事项 | 基准档 | 严格档 | 评审输入 |
|---|---|---|---|
| E14 同步、撤权与恢复 | 演练以事件入库同步 5 分钟、撤权传播 5 分钟、已确认关键提交 RPO 0 与 RTO 30 分钟为目标 | 演练以同步 1 分钟、撤权传播 1 分钟、已确认关键提交 RPO 0 与 RTO 10 分钟为目标 | 分别记录采集起止、持久化确认、撤权覆盖和分级恢复试验。普通事件及资源按业务影响另定 |
| E22 方法批准及传播 | 事先登记每个用途的验证指标、样本覆盖和阈值，按合成输入演练在线暂停传播 5 分钟 | 高后果用途增加独立复核和分层误差证据，按合成输入演练在线暂停传播 1 分钟 | 学科与业务评审为不同任务分别审定阈值和离线证明期限。记录每个执行点，禁止用访问令牌撤权时限替代 |
| E23b / E24 课程规则 | 先选一门试点课程，登记有效提交选择、撤回窗口和即时帮助的允许类型，公开告知学生 | 优先演练含个人延期和替代提交的课程；即时帮助默认关闭，逐活动批准后启用 | 考核方案、帮助级别与适用对象版本化，分别按课程和用途签署。未决定用途保持关闭，需人工确认的输出仍须确认 |
